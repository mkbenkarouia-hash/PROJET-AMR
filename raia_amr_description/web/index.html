🌐 Guide de Connexion & Architecture Réseau du Robot

Pour se connecter à l'interface de contrôle du robot industriel RAIA AMR 4.0, l'opérateur ou le technicien doit simplement se trouver sur le réseau de l'atelier.

Composant Embarqué Modèle & Spécifications Industrielles
Module Wi-Fi 6 Embarqué Moxa AWK-3252A (Client industriel IEEE 802.11ax / WPA3-Enterprise, Roaming sans perte < 50 ms)
Routeur 5G de Secours Teltonika RUTX50 (Réseau privé 5G Standalone Usine 4.0, failover automatique)
Antennes Châssis Double antenne omnidirectionnelle à fort gain (5 dBi) montées sur la superstructure haute du robot
Liaison au PC Embarqué Câble blindé M12 / RJ45 Gigabit Ethernet relié au port eth0 de l'unité de calcul (Ubuntu 22.04 LTS / ROS2 Humble)
Adresse IP du Robot 192.168.1.50 (ou nom d'hôte local : http://raia-amr.local:8080)

📋 Procédure de Connexion Opérateur :

  1. Connectez votre appareil (Tablette durcie, PC superviseur, smartphone d'atelier) au réseau Wi-Fi "FACTORY_INDUSTRY_4.0".
  2. Ouvrez votre navigateur favori (Google Chrome, Safari, Microsoft Edge, Firefox).
  3. Tapez dans la barre d'adresse : http://localhost:8080
  4. Le tableau de bord se charge immédiatement sans aucune installation requise.
